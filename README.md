# Landing page — 20 Panetones Trufados de Natal

Landing page estática, responsiva e pronta para GitHub Pages.

## 1. Configurar o checkout da Kiwify

Abra `script.js` e substitua:

```js
const CHECKOUT_URL = "COLOQUE_SEU_LINK_KIWIFY_AQUI";
```

pelo link real do checkout da Kiwify, mantendo as aspas.

## 2. Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `panetones-trufados-natal`.
2. Envie todos os arquivos desta pasta para a raiz do repositório: `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde o GitHub publicar e use o endereço apresentado em Settings → Pages.

## 3. Antes de divulgar

- Teste todos os botões no celular e no computador.
- Confirme que o checkout abre o produto correto e o preço está atualizado.
- Inclua política de privacidade, termos e identificação/contato do responsável, conforme a sua operação e as regras aplicáveis.
- Use apenas depoimentos, selos, garantias e alegações que sejam verdadeiros e comprováveis.
- A imagem principal é um visual gerado para esta página; revise o resultado visual no dispositivo antes de publicar.

## Arquivos

- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual e responsividade.
- `script.js`: link único do checkout e ano do rodapé.
- `assets/panetone-hero.jpg`: imagem principal.
